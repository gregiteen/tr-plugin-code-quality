# Marketing and Campaigns

1. Read the current repository's product brief, brand guidance, campaign code,
   audience model, consent rules, and email skill if one exists.
2. Identify the requested audience, purpose, offer, trigger, channel, and
   success measure from project evidence. Ask for a material missing choice.
3. Trace how opt-in, suppression, send, tracking, and unsubscribe actually work
   before scheduling or sending any message.
4. Draft copy in this project's voice and verify all product claims, prices,
   links, and provider connections before use.

The global skill does not define a site's funnel, discount, tone, or mail stack.
